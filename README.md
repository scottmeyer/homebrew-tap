# Homebrew tap

Homebrew packages maintained by [Scott Meyer](https://github.com/scottmeyer).

## nine-tails

After the first signed release:

```sh
brew install --cask scottmeyer/tap/nine-tails
```

`nine-tails` is a harness-independent context sidecar for AI coding agents.
See [scottmeyer/nine-tails](https://github.com/scottmeyer/nine-tails) for usage,
source, and release verification instructions.

Release automation owns the files under `Casks/`; manual changes there may be
replaced by the next release.
